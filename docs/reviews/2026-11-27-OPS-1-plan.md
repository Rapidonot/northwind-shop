- **Agent map:** one SVG built from `layout.json` (boxes and routes measured from the reference).
  Tests check generated nodes ⇄ boxes and generated edges ⇄ routes, both ways. The gateway's
  generator test reads the same file.

- **Cart writes on the catalog box:** shown as `+ cart write tools`. The generator derives them
  from `CART_TOOL_NAMES` minus `get_cart`, and asserts the result equals `CART_WRITE_TOOLS`.
