- (a) **Pair the order number's digits with the key's.** A good order number plus an all-digit key of 7 digits or more passes Luhn by

  error that asks for a random key, before any card check. With the 6 digits of an order number that leaves at most 12 joined
  digits, which can never be a card. **Recommended.** It refuses the pin's `4111-1111-11`, which is the pin change you would make.
  Measured at $0: none of the 1,612 idempotency keys in every recorded suite has a digit group longer than 6 (the return keys are

**Waits on it:** only L4. It is pinned as a strict xfail (`services/common/tests/test_18a_cards.py`), so the fix has a failing-first
