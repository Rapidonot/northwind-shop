NFR-08: AI disclosure in every chat session and every journey test (row #14, partial)

## What this does

- **The disclosure is its own element.** `AiDisclosure` renders "You're chatting with an AI assistant, not a person."
  as `role="note"`, named "AI disclosure". `Chat` renders it, outside the streamed answer and the alert. It has no
  props and no state, so no token, error, refusal or new question can clear or change it. The price and stock
  sentence is now a separate line, with its wording unchanged.
- **Every journey test checks it.** Playwright tests now take `test` from `apps/portal/e2e/journey.ts`. Its automatic
  fixture asserts, at the end of every test, that the disclosure is visible with its exact text. `chat.e2e.ts` uses
  it, with its body unchanged.
  - A Vitest guard fails if any `e2e/*.e2e.ts`:
    - does not import `test` from `./journey`;
    - imports anything outside `./journey` and `./questions.json`;
    - uses a dynamic import;
    - sits in a subdirectory.
  - The guard also fails if `journey.ts` stops being automatic or stops asserting after the test body.
- **New browser tests, `[NFR-08]`:** the disclosure is shown on load, after a reload, and after the gateway refuses
  a 2,001-character message with a 422. None of them sends anything to the model.
- **Unit tests, `[NFR-08]`:** the disclosure is shown on mount and through every turn state. Exhaustive
  `ChatEvent` and `ErrorCode` maps make a new event type or error code a compile error until it is covered.
- **The model's own disclosure (A4).** A read-only pytest checks two things: the system prompt says it is an AI and
  never claims to be a person, in all four regions; and `turn.py` sends that prompt, checked by parsing the code.

No model input changes, nothing is recorded, and spend is $0. No control-surface file is changed.
