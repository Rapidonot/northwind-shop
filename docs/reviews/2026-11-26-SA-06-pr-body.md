## Why
SA-06: a shopper who asks for a person is handed off at once, and staff get a case with identity, intent, root
cause, amounts and recommended action. NFR-08 (rest, from #14): the shopper is told a person will take over. The
user's hard constraint: the Shopper Assistant gets no case-creating or case-assigning tool (PRD §7, hard rule 8).
Plan: `docs/reviews/2026-11-26-SA-06-plan.md`, approved by the user with four changes. Decision 0025.

## What this does
- **Two triggers, both deterministic, both before any search or model call:**
  - a "Talk to a person" button, always shown;
  - a code-only phrase matcher in `/api/chat`. It runs after the card refusal, and a match gets `handoff` and `done`.

  Both go to `POST /api/handoff`, which takes `application/json` only, at most 10 turns, and refuses card data with
  chat's 422.
- **Identity comes from the server only:** the signed-in shopper, or `session_ref`, an HMAC of the session ID in
  letters a–p. It is never the session ID.
- **The desk opens the handoff at once** (202, a reference, fixed text), with one open handoff per identity (hard
  rule 9). The Care agent builds the case after.
- **Code fills in the case. The model writes only the summary:**
  - Intent: a closed set, from keyword rules.
  - With an order the shopper owns: BE-07's `run_care`, unchanged (model input sha256-pinned to main). The handoff
    points to its case.
  - Without one: a summary-only Care variant (`run_summary`, `submit_summary` only). The root cause is
    `shopper_requested`, the action comes from a code table, and the amounts from the live cart (`no_amounts` when
    it is empty).
  - If the Care run fails or every slot is busy, the case is still queued (`summary_missing`, `care_busy`).
- **The assistant gets no tool for this.** Its prompt and tools are unchanged. A test pins that no tool or server it
  is given names a case, a handoff or similar, and `case` is now a forbidden fragment in `tool_scopes.py`.
- **Portal:** a fixed notice (a person from the care team will take over; until then, it is still an AI). The AI
  disclosure stays. A "joined" state is driven only by a test fake, because no staff side exists yet.
