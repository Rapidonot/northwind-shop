**The shared-index protocol for the judged phase (change 1).** Postgres is shared by every worktree.
1. **Before every step that reads or writes the index, each window runs the read-only index check for its
   own DATA_VERSION.** That means `data_version`, an `index_version` prefix, and a `dataset_sha256` equal to
   that checkout's `data/fixtures/manifest.json`. A window whose check fails stops; it does not repair the index.
2. **A window re-ingests only its own version, and only when its plan says so.** #32 re-ingests v3 at §9 step
   2 only. Window A re-ingests v2 only where its own plan says so.
3. **Window A stays idle during #32's v3 recording windows**: from #32's v3 re-ingest to the last runner window
   that reads the index (run 1, runs 2 and 3, the judge repeat, the re-records).
4. Until #32 merges, a v2 ingest by window A would delete R01222 to R01224 and make #32's recordings stale.
   This is why rule 3 exists. After #32 merges, main is v3, and window A moves to v3 when it merges main.
